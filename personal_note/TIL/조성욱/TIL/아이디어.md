# 운동 루틴 & 헬스장 기계 사용 순서 자동 지정
- 자극을 주고 싶은 부위를 설정하면 헬스장에 있는 기구중에 어떤 기구를 사용하여 운동할지 추천해줌
- 운동 루틴을 등록하면 헬스장 기계 사용 목록에 등록하여 기계를 사용할 수 있는 시간을 지정해줌
- 특정 기구를 사용하기위해 눈치보며 기다리는 시간을 최소화하는 목적

# 물건 공유
- 특정 물건이 필요할 때 판매하는 상품을 찾는 것이 아니라 내가 구하려는 상품을 등록하면 주위 사람에게 알림이 가게 됨
