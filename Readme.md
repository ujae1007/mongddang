# 여행/음악 플레이리스트

<aside>

# 1️⃣ 서비스 설명 / 주요 기능

### 서비스 설명

- 노래가 불러일으키는 향수로 떠나는 추억 여행 서비스
- 노래가 불러 일으킬 수 있는 **향수**로 과거 여행을 추억하는 서비스
- 사진과 음악을 결합하여 여행의 순간과 감성을 기록하고 추억하는 서비스

### 주요 기능

- 여행 모먼트 기록
    - 위치 기반 사진 업로드
    - 음악 연동 시스템
        - 음악 앱 캡쳐를 통한 자동 등록 (곡명/아티스트/재생 시간 추출)
        - AI 기반 사진 감정 분석 맞춤 음악 추천
- 여행 스토리 생성
    - 커스텀 플레이리스트 생성
    - 위치 기반 여행 동선 시각화
        - 인스타그래머블한 여행 루트 이미지 제작
        - 사진 촬영 장소 자동 매핑
- 공유 및 발견
    - 커스템 플레이리스트 공유
    - 지역별 플레이리스트 추천
        - 음악 취향 유사도 분석
        - 계절/시간대 기반 매칭

---

- 여행 스팟별로 사진과 노래 업로드
- 노래 업로드 방식
    - 직접 업로드
        - 듣고 있는 어플 화면 캡쳐 → 가수/제목/캡쳐 됐을 때 노래 시작 시간
    - 추천
        - 사진 + 감정 기반 노래 추천
        - 사진으로만 감정 추출
- 여행이 끝나면 하나의 플레이리스트 생성 후 공유
- 지역별 플레이리스트 유사도 추천
    - 플레이리스트 구성도(얼마나 비슷한지), 계절감 등등등
- 사진을 업로드 한 위치에 마크
    - 위치 동선을 한 눈에 볼 수 있는 이미지 생성 → 인스타 업로드 용
</aside>

<aside>

# 2️⃣ 프로젝트의 특장점(기능 관점)

- 원스톱 여행 기록 솔루션
    - 사진, 위치, 음악을 하나의 스토리로 자동 구성
    - 여행이 끝난 후 자동으로 완성되는 테마별 플레이리스트
    - 순간의 감정과 기억을 복합적으로 저장
- 음악-사진 자동 매칭 시스템
    - 사진 업로드 시 듣고 있던 음악을 캡쳐만으로 간편하게 연동하여 순간의 감정과 기억을 생생하게 기록
    - AI 기반으로 사진의 분위기를 분석해 어울리는 음악 자동 추천
- 스마트 여행 루트 시각화
    - 심미적으로 디자인된 맞춤형 지도 이미지 제작 및 SNS 공유에 최적화된 포맷으로 자동 변환
- 맥락 기반 플레이리스트 매칭
    - 위치, 계절, 시간대를 고려한 지능형 음악 추천
    - 다른 여행자들의 플레이리스트와 취향 유사도 분석
    - 방문 시기별 인기 음악 트렌드 제공
- 소셜 뮤직 트래블 플랫폼
    - 음악 취향 공유로 음악을 통한 새로운 여행지 발견 경험
    - 다른 여행자들의 루트와 플레이리스트 탐색
</aside>

<aside>

# 3️⃣ 프로젝트의 차별점/독창성(기술 관점)

- 이미지-음악 감정 분석 AI 시스템
    - 딥러닝 기반 이미지의 분위기/감정 추출하여 이미지-음악 간 감성적 연관성 분석 알고리즘
- 음원 인식
    - 음악 앱 스크린샷 OCR 처리 기술
- 동적 경로 시각화 엔진
    - 커스텀 맵 스타일링 랜더링 시스템을 통하여 SNS 최적화 이미지 자동 생성 기술
- 개인화 추천 시스템
    - 협업 필터링 기반 플레이리스트 추천
    - 공간 컨텍스트 기반 음악 매칭
